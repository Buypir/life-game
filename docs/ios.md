# iOS-застосунок без App Store і без $99

Гра збирається як справжній iOS-застосунок (Capacitor) у хмарі на Mac, а на iPhone ставиться з
Windows твоїм звичайним Apple ID.

## Що працює в застосунку

| Можливість | Як |
| --- | --- |
| Нагадування про квести, справи й кінець фокусу | локальні сповіщення, сервер не потрібен |
| Справжній будильник (iOS 26+) | AlarmKit: дзвонить крізь беззвучний режим і фокус, «Стоп» на заблокованому екрані |
| Поїздки дім / офіс / зал | геозони iOS — працюють і з закритою грою, приходить сповіщення «Герой в офісі» |
| Siri, Spotlight, кнопка дії | «Відмітити справу»: «Mark brush in Life Game» (Siri не говорить українською, тому фраза англійською) |
| Пара, копія на сервері, ESP32, Apple Health | як і раніше — через сервер (розділ «Нагадування» → «Сервер») |

## 1. Зібрати LifeGame.ipa

**GitHub Actions** (вже є в репозиторії): GitHub → вкладка **Actions** → **iOS app** → **Run workflow**.
Через ~10 хв у запуску з'явиться артефакт **LifeGame-ipa** — завантаж і розпакуй, там `LifeGame.ipa`.
Збірка також запускається сама після кожного push у `main`.

**Codemagic** (запасний варіант): codemagic.io → увійти через GitHub → додати репозиторій →
він знайде `codemagic.yaml` → **Start new build**. IPA буде в артефактах.

## 2. Поставити на iPhone (Windows)

1. Встанови **iTunes** і **iCloud** з сайту Apple (не з Microsoft Store) — потрібні драйвери iPhone.
2. Встанови **Sideloadly** (sideloadly.io).
3. Під'єднай iPhone кабелем, на телефоні натисни «Довіряти».
4. Перетягни `LifeGame.ipa` у Sideloadly, введи свій Apple ID → **Start**.
   Пароль іде лише в Apple; для надійності можна завести окремий Apple ID для підпису.
5. На iPhone: **Параметри → Загальні → VPN і керування пристроями** → свій Apple ID → «Довіряти».
6. **Параметри → Приватність і безпека → Режим розробника** → увімкнути й перезавантажити телефон.
7. Відкрий гру й дозволь сповіщення, геолокацію («Завжди» — для поїздок) і будильники.

## 3. Раз на 7 днів

Безкоштовний підпис діє 7 днів. Потім застосунок перестає відкриватися (дані лишаються) —
просто повтори крок 4. Щоб не думати про це:

- у Sideloadly увімкни **Auto-refresh** — він сам перепідписує, коли телефон і ноут в одній Wi-Fi;
- або встанови **AltStore** (altstore.io) з **AltServer** на Windows — теж оновлює сам.

Обмеження безкоштовного Apple ID: до 3 таких застосунків одночасно, без пуш-сповіщень із сервера
(сповіщення про квести працюють — вони локальні).

## Перенести прогрес із веб-версії

Веб-версія й застосунок мають окремі дані. У веб-версії: «Герой» → «Резервна копія» →
«Зберегти копію», потім у застосунку → «Відновити з файлу».

## Якщо збірка впала

Swift-код (будильник, геозони, Siri) перевіряє лише збірка на Mac. Відкрий лог упалого кроку
**Build unsigned IPA** і скинь мені останні рядки з `error:` — виправлю.
