# Пристрій-компаньйон на ESP32

Маленький екран на столі, де живе твій герой: показує рівень, серію, монети й наступну справу.
Кнопка «Готово» відмічає справу в грі (як команда Siri), а в час нагадування пищалка будить,
якщо квест ще не виконано.

## Деталі

| Що | Приклад |
| --- | --- |
| Плата | ESP32 DevKit (будь-яка з Wi-Fi) |
| Екран | OLED 0.96" 128×64, SSD1306, I2C |
| Кнопки | 2 тактові кнопки |
| Звук | пасивна пищалка (buzzer) |

## Підключення

| ESP32 | До чого |
| --- | --- |
| 3V3 / GND | VCC / GND екрана |
| GPIO 21 | SDA екрана |
| GPIO 22 | SCL екрана |
| GPIO 32 | кнопка «Готово» → GND |
| GPIO 33 | кнопка «Далі» → GND |
| GPIO 25 | пищалка (+), мінус → GND |

Кнопки підтягнуті внутрішніми резисторами, зовнішні не потрібні.

## Прошивка

1. Увімкни сповіщення в грі й створи посилання: «Герой» → «Автоматизації iPhone» → «ESP32» → «Копіювати».
2. `cp src/config.example.h src/config.h` і заповни Wi-Fi та `DEVICE_URL`.
3. `pio run -t upload && pio device monitor` (PlatformIO у VS Code або CLI).

## Як працює

- Раз на хвилину пристрій бере `GET /api/device/{ключ}`: ім'я, рівень, серія, монети, найближчі
  справи, виконані квести й час нагадувань.
- «Готово» → `POST /api/act/{ключ}/{id справи}`. Гра зарахує справу, коли її відкриєш, а пристрій
  одразу показує наступну.
- «Далі» перемикає екран героя й список нагадувань; під час будильника — вимикає його.
- Будильник дзвонить до 2 хвилин у межах 10 хв після часу нагадування, якщо квест ще не виконано.

Логіку без заліза (будильник, черга справ, URL) перевіряють тести на комп'ютері:

```bash
cd device/test && g++ -std=c++17 -I../src test_logic.cpp -o test_logic && ./test_logic
```

> Тулчейн ESP32 тут був недоступний: прошивку перевірено тестами логіки та компіляцією з
> справжнім ArduinoJson і заглушками Arduino/U8g2/WiFi. На залізі її ще не запускали, тож перший
> запуск може потребувати дрібних правок.
